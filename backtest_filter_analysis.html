Executive Summary

Session filter (NY 13–22 UTC) is universally beneficial. It improves profit factor, win rate, and drawdown across all three timeframes (1h, 5m, 15m). Weekday filter alone hurts performance; only combine it with session filter for best results.

Key Findings

Session Filter Impact (NY 13–22 UTC)

UNIVERSAL WIN

  • 1h: PF ↑67%, DD ↓67%, WR +5%
  • 5m: PF ↑78%, DD ↓33%, WR +13%
  • 15m: Flips negative → positive, PF ↑117%, WR +17%

Why: NY session has higher liquidity and cleaner FVG formations. Low-volume overnight/Asian hours produce noisy signals that fail.

Weekday Filter Impact (Mon–Fri UTC)

USE WITH SESSION ONLY

  • 1h: Alone: hurts all metrics
  • 5m: Alone: slight regression (DD ↑17%)
  • 15m: Alone: worsens loss (−3R vs −4R)

With session: Improves all three. Best when combined with session filter.
